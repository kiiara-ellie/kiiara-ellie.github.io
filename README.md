# 키아라 평택 - 눈썹문신 전문

평택 눈썹문신 전문 키아라의 공식 웹사이트입니다.

## 🌟 주요 기능

- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모든 기기에서 최적화
- **SEO 최적화**: 검색 엔진 최적화 완료 (메타 태그, 구조화된 데이터, sitemap)
- **성능 최적화**: 이미지 lazy loading, 비디오 최적화
- **포트폴리오 라이트박스**: 이미지 확대 보기 및 슬라이드 기능
- **스무스 스크롤**: 부드러운 페이지 네비게이션
- **접근성**: ARIA 레이블, 키보드 네비게이션 지원
- **모던 타이포그래피**: Pretendard 폰트 적용

## 📱 섹션 구성

1. **Hero**: 메인 비디오 배경과 헤드라인
2. **소개**: 서비스 소개
3. **1:1 맞춤 상담**: 상담, 시술, 케어 프로세스
4. **Portfolio**: 실제 시술 사례
5. **Q&A**: 자주 묻는 질문
6. **고객 후기**: 실제 고객 리뷰
7. **오시는 길**: 위치 및 영업 정보
8. **예약 문의**: 다양한 연락 방법

## 🛠 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Pretendard Font
- Schema.org 구조화된 데이터

## 🚀 성능 최적화

- 이미지 lazy loading
- 비디오 preload 최적화
- 폰트 preload
- Intersection Observer API 활용
- 스크롤 이벤트 throttling
